# 065 — "연결 기기": 기기마다 세트리스트만 고른다 (0.8.1)

작성일: 2026-09-28
상태: ✅ 구현 · 테스트 · 배포

## 요청
- 웹에서 기기를 설정할 때 **세트리스트만** 고르게 한다. "모든 악보" 선택지는 없앤다
- 세트리스트 화면에는 기기 설정을 두지 않는다
- 메뉴 이름 "TV" → **"연결 기기"**. 태블릿으로도 넓힐 것이기 때문이다

## 바꾼 것
- **연결 기기 화면**(`devices/list.html`)
  - 기기 카드마다 "받을 세트리스트" 체크 목록 하나. 라디오와 "모든 악보"는 없다
  - 예전 `all` 기기에는 "지금은 예전 설정대로 모든 악보를 받고 있습니다" 안내가 뜬다. 저장하면 `setlists` 가 된다
  - 흐리게 하던 JS · `.option.all-selected` CSS 를 지웠다
- **기기 연결 확인 화면**(`activate.html`): 세트리스트 체크 목록만 있다. `sync_mode` 는 보내도 무시하고 늘 `setlists`
- **`device_sync` 뷰**: `sync_mode` 를 받지 않는다. 늘 `set_sync(device, SYNC_SETLISTS, 고른 것)`
- **세트리스트 화면**: "보낼 TV" 절을 지웠다. `setlist_devices` 뷰 · URL, 그 뷰만 쓰던 `devices.services.toggle_setlist` 도 지웠다
- **문구**: 메뉴 · 제목 "연결 기기", 버튼 "기기 연결", 기기 화면 안내 · 메시지 · 폼 라벨을 기기 중립으로 바꿨다(로그인 화면 "TV · 태블릿으로")

## `sync_mode='all'` 은?
- 웹에는 선택지가 없다. API 는 원래 읽기 전용이고, 새 기기 기본값은 `setlists` 다
- 그래서 **새로 `all` 이 되는 길은 없다**(Django admin 에서 직접 바꾸는 것 말고)
- 서버 모델 · 동기화 코드에는 값이 남아 있다. 이유는 둘:
  - 사용자 토큰(기기 아님)의 동기화가 원래 "전부"다
  - `tests/test_sync.py` · `test_multi_device.py` 가 전체 보관함 동기화 규칙(앙상블 가입 시각 등)을 `all` 기기로 검증한다
- 운영(2026-09-28): 기기는 `Z18TV_Test` 하나다. 이미 `setlists` 이고 세트리스트 1개를 골라 두었다
- 완전히 지우려면: 데이터 마이그레이션(`all` → `setlists`) + choices 에서 제거 + 위 테스트를 세트리스트 기준으로 다시 쓴다

## 테스트 — 전체 360 통과

  - 예전 `all` 기기 안내와 저장 뒤 전환
