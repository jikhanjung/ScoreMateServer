## 3. S1 구현

### 모델 (`ensembles` 앱 신설)
```
Ensemble     name, description, created_by, created_at, updated_at
Membership   ensemble, user, role(owner|leader|member), part, joined_at   unique(ensemble, user)
Invite       ensemble, code(10자, 헷갈리는 글자 · 모음 제외), created_by, expires_at(기본 7일, null=없음),
             max_uses(null=무제한), uses, revoked_at
Score (+)    ensemble (null=개인, SET_NULL), part_name
```
- 앙상블을 지우면 악보는 지우지 않고 **올린 사람의 개인 악보로 돌아간다** (SET_NULL). 쿼터가 그 사람 것이기 때문
- 쿼터는 **올린 사람 기준** — 리더가 멤버의 악보를 지워도 올린 사람에게 돌려준다 (이전에는 지운 사람에게서 뺐다)

### 권한 — 한 곳에서
`Score.objects.readable_by(user)` / `writable_by(user)` (ScoreQuerySet). 악보를 찾는 모든 경로가 이 둘 중 하나를 거친다.

| | 읽기 | 쓰기(수정 · 삭제 · 썸네일/정보 다시 만들기 · 일괄) |
|---|---|---|
| 개인 악보 | 올린 사람 | 올린 사람 |
| 앙상블 악보 | 멤버 | owner · leader |

- 비멤버: 404 (있는지도 알리지 않음). 멤버가 쓰려 하면 403
- 올린 사람이라도 앙상블을 나가면 그 앙상블 악보는 안 보인다
- 앙상블에 올리기(생성 · upload-confirm · 옮기기)는 owner · leader. 개인 ↔ 앙상블 옮기기는 **올린 사람만**
- 수정 시리얼라이저에서 `user`(HiddenField) 를 뺐다 — 그대로면 리더가 고칠 때 올린 사람이 리더로 바뀌었다.
  파일 필드(`s3_key`, `size_bytes`, `mime`, `thumbnail_key`, `content_hash`)도 수정 불가로 (PATCH 로 크기를 바꿔 쿼터를 속일 수 있었다)
- 목록 응답에 `ensemble`, `ensemble_name`, `part_name`, `uploader`, `can_edit`. `can_edit` 는 요청당 멤버십을 한 번만 조회
- 필터: `?ensemble=<id>` / `?ensemble=personal`, `?part_name=`
- 다운로드(`download-url`, `direct-download`)도 `readable_by`

멤버 관리 규칙:
- 역할 변경은 owner 만. 파트는 owner · leader, 또는 본인
- 내보내기: owner 는 누구나, leader 는 member 만. 누구나 스스로 나갈 수 있다
- owner 는 적어도 한 명 — 마지막 owner 는 강등 · 탈퇴 불가(400). 다른 사람을 owner 로 세우고 나간다

### API (`/api/v1/ensembles/`)
```
GET  POST        ensembles/                            내 앙상블(my_role, my_part, member_count, score_count) · 만들기(→ owner)
GET PATCH DELETE ensembles/{id}/                       상세(members 포함) · 수정(owner·leader) · 삭제(owner)
GET              ensembles/{id}/members/
PATCH DELETE     ensembles/{id}/members/{user_id}/     {role, part} · 내보내기/나가기
GET POST         ensembles/{id}/invites/               owner·leader. POST {expires_in_days?, max_uses?}
DELETE           ensembles/{id}/invites/{invite_id}/   취소
GET              ensembles/invite/{code}/              미리 보기(이름 · 인원 · 만료) — 멤버 · 악보는 가입 전 비공개
POST             ensembles/join/ {code}                가입(member). 이미 멤버면 200, 역할 그대로
```
- 코드는 대소문자 · 하이픈 무시 (`bcdfg-HJKMN` 도 된다). 없는 코드와 만료된 코드를 구별해 알려 주지 않는다
- 미리 보기 · 가입은 `invite` 스코프 요청 제한 **30/시간**
- 사용 횟수 증가는 `select_for_update` 트랜잭션 안에서
