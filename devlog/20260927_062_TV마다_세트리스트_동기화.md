# 062 — TV 마다 받을 것: 고른 세트리스트의 곡만(기본) / 모든 악보 (0.7.0)

작성일: 2026-09-27
상태: ✅ 구현 · 테스트 · 배포

## 결정
- TV 는 **고른 세트리스트의 곡만** 받는 것이 기본. 보관함 전체가 아니라 지금 연주할 곡만 TV 에(저장 공간 · 리모컨으로 고르기 · "이번 곡목을 TV 로" 라는 실제 쓰임)
- **고르는 곳은 웹(서버)뿐** — TV 는 API 로 보기만(`devices/me/` 의 `sync_mode` · `sync_setlists`, 읽기 전용)
- 기존 기기(이 변경 전 연결)는 **모든 악보**로 둔다(마이그레이션) — 운영 TV 1대가 갑자기 비지 않게. 웹에서 바꿀 수 있다

## 서버
- `Device.sync_mode`(`setlists` 기본 · `all`), `DeviceSetlist(device, setlist, added_at)`
- 동기화(`scores/sync.py`): 기기가 `setlists` 면 `scores` · `ids` 를 **그 기기가 고른(지금 읽을 수 있는) 세트리스트의 곡**으로 좁힌다.
  기준 시각에 max(곡이 곡목에 들어간 시각, 곡목을 이 기기로 고른 시각)를 더한다 — 곡을 넣거나 곡목을 고르면 옛 악보라도 온다(앙상블에 들어온 경우와 같은 방식).
  이 기기의 `added_at` 만 본다(filter 를 annotate 보다 먼저 — 다대다 조인을 같게. 순서를 바꾸면 다른 TV 가 고른 시각이 섞인다)
- 곡을 빼거나 곡목을 해제하면 `ids` 에서 빠진다 → TV 가 정리(TV 앱 변경 없음). 악보 자체는 그대로
- `sync/setlists/` 도 기기가 `setlists` 면 고른 것만
- 웹 · 사용자 토큰(기기 아님)은 전처럼 전부

## 웹
- TV 화면: 기기마다 "받는 것" 요약 + 고르기(고른 세트리스트 체크 / 모든 악보)
- 세트리스트 화면: "보낼 TV" 체크 — 읽을 수 있는 세트리스트면 누구나 자기 TV 로
- TV 연결 확인 화면: 연결하면서 바로 고른다

## TV 앱
변경 필요 없음 — 이미 `ids` 에 없는 악보를 정리한다. "모든 악보" → "세트리스트만" 으로 바꾸면 한꺼번에 많이 빠져 TV 의 안전장치가 한 번 확인을 물을 수 있다(의도한 동작).

## 테스트 — `tests/test_device_setlist_sync.py` 10개, 전체 350
새 기기 기본 · 곡목의 곡만 · 곡 넣기/곡목 고르기로 옛 악보가 옴 · 빼기/해제로 ids 에서 빠짐 · 다른 TV 의 고른 시각이 새지 않음 ·
모든 악보 · 사용자 토큰은 전부 · API 로 못 바꿈 · 웹 고르기 · 연결하면서 고르기.
"넣은 · 고른 시각" 규칙을 빼도 처음엔 테스트가 통과했다 — 모든 악보가 같은 시각이라 id 동률 규칙으로 우연히 커서 뒤에 놓였다(060 과 같은 함정).
새로 넣는 악보를 커서보다 확실히 옛날로 두어 고쳤고, 두 규칙 모두 빼면 실패한다.
