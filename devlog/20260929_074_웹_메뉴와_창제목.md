# 074 — 웹 메뉴 · 창 제목 정리: 악보 관리 · 기기 관리 (0.12.3 · 0.12.4)

작성일: 2026-09-29
상태: ✅ 구현 · 테스트 · 배포 (운영 0.12.4, 백엔드 테스트 499 통과)

## 요청
1. "윈도우 Title 에 ScoreMate 를 제일 앞에 놔줘. 악보 · ScoreMate 말고 ScoreMate · 악보 — 그래야 무슨 탭인지 금방 알아보지."
2. "탑 메뉴에서 [올리기]는 삭제." · "악보 메뉴에서 [올리기] 버튼은 [악보 추가]로 바꿔주고."
3. "세트리스트는 악보의 하위 카테고리여야겠네."
4. "최상위 메뉴: 악보 → 악보 관리, 연결 기기 → 기기 관리"

## 바뀐 것
### 창(탭) 제목 — 0.12.3
- `base.html`: `<title>{% block title %}…{% endblock %} · ScoreMate</title>` → **`<title>ScoreMate · {% block title %}악보{% endblock %}</title>`**
- 모든 화면이 제목 블록을 가진다(확인) → "ScoreMate · 로그인", "ScoreMate · 악보", "ScoreMate · Die Moldau (Vltava)" …
  - 탭이 좁아도 앞의 "ScoreMate"가 보인다

### 메뉴 — 0.12.3 · 0.12.4
| 전 | 후 |
|---|---|
| 악보 · 세트리스트 · 올리기 · 연결 기기 (+ 앙상블, 지금은 숨김) | **악보 관리 · 기기 관리** (+ 앙상블, 숨김) |

- **올리기**: 위쪽 메뉴에서 뺐다
  - 악보 목록의 버튼 "올리기" → **"악보 추가"**
  - 올리기 화면의 제목 · 머리말도 "악보 추가"로 바꿨다
  - 그 화면에서는 "악보 관리"가 켜진다
  - 앙상블 화면의 "악보 올리기" 링크는 그대로 뒀다(앙상블 메뉴는 숨김)
- **세트리스트 → 악보 관리의 하위 탭**
  - 새 조각 `web/_library_tabs.html`: "**모든 악보 | 세트리스트**"(아래 줄 · 켜진 탭은 강조색 밑줄, `.subtabs`)
  - 넣은 곳: 악보 목록, 세트리스트 목록, 세트리스트 상세. 주소(`/scores/`, `/setlists/`)는 그대로다
  - 세트리스트 화면에서도 위쪽 "악보 관리"가 켜진다
  - 세트리스트를 음악 앱의 플레이리스트처럼 악보 보관함의 한 보기로 본 것이다(devlog 062 의 결정과 같은 결)
- **기기 관리**: 위쪽 메뉴 · 화면 제목 · 머리말을 "연결 기기" → "기기 관리"로 바꿨다
  - 기기 연결 확인 화면의 안내도 "'기기 관리' 화면에서 고르세요"로 바꿨다
