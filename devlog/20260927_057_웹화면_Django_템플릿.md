## 1. 화면 (`backend/web/`, 세션 로그인)

| 경로 | 화면 |
|---|---|
| `/login/` · `/register/` · 로그아웃(POST) | 이메일 로그인. 가입은 `REGISTRATION_OPEN`(기본 켜짐) — 끄면 웹 · API 가입이 함께 닫힌다 |
| `/scores/` | 내 악보 + 내 앙상블 악보. 검색(제목 · 작곡가 · 편성 · 파트), 어디의 악보(전체 · 내 악보 · 앙상블별), 24개씩 |
| `/scores/upload/` | PDF 여러 개 한 번에. 올릴 곳 = 내 악보 또는 **내가 owner · leader 인 앙상블**. 여러 파일에 제목을 주면 **각 파일 이름이 파트** (블타바 + `Guitar 1.pdf` …) |
| `/scores/<id>/` | 첫 쪽 썸네일 · 정보 · **보기**(브라우저 PDF 뷰어) · **받기** · 고치기 · 지우기(쓸 수 있는 사람만) |
| `/ensembles/` | 내 앙상블(역할 · 파트 · 인원 · 악보 수), 새로 만들기, 초대 코드 입력 |
| `/ensembles/<id>/` | 악보를 **곡별로 묶어 파트 칩**으로(총보가 맨 앞), 멤버(역할은 owner, 파트는 owner · leader · 본인), 내보내기 · 나가기, 초대 링크 만들기 · 복사 · 취소, 정보 수정, 지우기(owner) |
| `/join/<code>/` | 초대 미리 보기 → 들어가기. 로그인 전이면 로그인(가입) 뒤 돌아온다. 사용자당 시간당 30번 |
| `/account/` | 저장 공간 · 비밀번호 바꾸기 |

- 보기 · 받기는 짧은 서명 URL 로 302 — 파일은 Django 를 지나지 않는다(nginx X-Accel)
- 로그인 실패 제한: (이메일, IP) 마다 15분에 10번
- JS 없이 동작한다. 링크 복사 · 되돌릴 수 없는 버튼 확인 · 업로드 중 버튼 잠금만 JS
- 라이트/다크, 좁은 화면에서는 메뉴가 한 줄 아래로, 멤버 · 초대 표는 세로로 쌓인다 (Playwright 로 1280px 라이트 · 390px 다크 캡처해 확인)

## 2. 규칙은 한 곳에 — API 와 웹이 같은 함수

- `ensembles/services.py`: 만들기 · 역할/파트 변경(owner 만 역할, 마지막 owner 보호) · 내보내기/나가기 · 초대 만들기/취소 · 코드 찾기 · 가입
- `scores/services.py`: `create_score`(쿼터 · 처리 시작) · `delete_score`(올린 사람에게 쿼터 반환 · 파일 삭제)
- API 뷰(EnsembleViewSet · ScoreViewSet.destroy · upload-confirm)를 이 서비스로 옮겼다 — 기존 API 테스트 208개가 리팩터링을 검증
- **버그 1 — 웹에서 처음 드러남**: 쿼터 갱신이 `type(user).objects` 였는데 웹의 `request.user` 는 `SimpleLazyObject` → `get_user_model()`
