# 067 — 악보 상세에서 쪽마다 보기 (0.9.3 · 0.9.4 · 0.9.5)

작성일: 2026-09-28
상태: ✅ 구현 · 테스트 · 배포

## 요청
"악보 정보 상세 페이지에서 페이지별로 악보 볼 수 있게 해줘."

이전에는 "보기"(브라우저 PDF 뷰어, 새 창)와 표지 썸네일(300×400)뿐이었다. 표지 썸네일은 읽기에는 작다.

## 방식 — 처음 볼 때 그 쪽만 그려 캐시
- `scores/pages.py`
  - `page_image_key(score, version, n, size)`: 저장소에 없으면 PyMuPDF 로 그 쪽만 그려(JPEG) 두고 키를 돌려준다
  - 크기 두 가지: `thumb` 가로 320px(q70), `view` 가로 1600px(q85)
  - 키: `{user}/scores/{score}/pages/{판 해시 앞 16자}/{size}-{쪽:04d}.jpg` — 판(파일)이 바뀌면 키가 바뀐다
- 웹 `score_page`(`/scores/<id>/pages/<n>/?size=`)
  - 읽기 권한을 확인한 뒤 서명 URL 로 302 — 파일은 Django 를 지나지 않는다
  - `Cache-Control: private, max-age=600`: 같은 쪽을 다시 볼 때 요청을 줄인다
- 미리 다 그려 두지 않는다. 42쪽 악보도 사람이 보는 쪽만 그린다. 운영 Moldau 기준 한 쪽: thumb 0.02초 · 19KB, view 0.2초 · 266KB
- 지우기
  - `delete_version`: 그 판의 해시 폴더. 다른 판이 같은 파일이면 남긴다
  - `delete_score`: `pages/` 전체. `score.delete()` 뒤에는 pk 가 없으므로 접두어를 먼저 계산한다
- 저장소에 `delete_prefix()` 추가: local 은 폴더 삭제 + 빈 상위 정리, S3 는 list + delete_objects
- 쪽 이미지는 쿼터에 넣지 않는다(표지 썸네일과 같다). `files/` 아래라 오프사이트 백업에 들어가지만 작다

## 화면
- 상세 화면에 **"쪽 (N)"** 격자
  - 작은 이미지는 `loading="lazy"`
  - 판이 아직 처리 중(해시 없음)이면 보이지 않는다
- 누르면 `<dialog>` 보기
  - 위 막대: ‹ · "3 / 42" · › · 닫기
  - ← → · PageUp/PageDown · 스페이스, 이미지 왼쪽 절반 / 오른쪽 절반 누르기로 넘긴다
  - 다음 쪽 큰 이미지를 미리 받는다
- `dialog` 를 모르는 브라우저에서는 링크가 새 창으로 큰 이미지를 연다

## 테스트 — `tests/test_score_pages.py` 5개, 전체 378 통과
- 상세에 쪽 수만큼 격자

## 0.9.4 — 너비 맞춤 · 높이 맞춤 (요청: "툴바에 fit to width, fit to height")
- 보기 막대에 두 버튼(`aria-pressed`, 고른 것은 강조색). 키 W · H
  - 너비 맞춤: `width:100%` — 가로를 채우고 세로로 스크롤
  - 높이 맞춤: `height: calc(100dvh - 막대 높이)` — 한 쪽이 한 화면에. 막대 높이는 열 때 · 창 크기가 바뀔 때 잰다(`--bar-h`)
- 보기 창을 화면 전체 너비로 넓혔다(전엔 최대 1100px)
- 쪽을 넘기면 맨 위로 스크롤한다
- 기억: `localStorage` `scoremate.pageFit`(try/catch — 막힌 브라우저에서도 동작). 처음엔 가로 화면이면 높이, 세로 화면이면 너비
- 확인: 로컬 데모 서버 + 헤드리스 Chromium, Moldau 2쪽
  - 데스크톱 1400×900: 너비 1400×1980(스크롤) / 높이 602×851(한 화면)
  - 휴대폰 390×844: 너비 390×552 / 높이 562×795
  - → 키로 3/13

## 0.9.5 — 1쪽 · 2쪽 (요청: "한 쪽씩 보여주기, 두 쪽씩 보여주기도 선택")
- 막대에 1쪽 / 2쪽(키 1 · 2). 보기 창의 이미지를 둘로 늘렸다(`[data-spread-box]` 안의 `img` 두 개)
- 2쪽
  - 1–2, 3–4 … 로 짝짓는다. 어느 쪽을 눌러도 그 쌍의 앞 쪽부터 보이고, 넘기기도 두 쪽씩
  - 마지막 홀수 쪽은 혼자 보인다. 카운터는 "3–4 / 13"
- 맞춤과 함께
  - 너비 맞춤: 2쪽이면 각 `calc(50% - 2px)`
  - 높이 맞춤: 각 쪽 높이 = 화면 − 막대. 두 쪽이 화면보다 넓으면 가로 스크롤(휴대폰)
- 다음 쌍의 큰 이미지를 미리 받는다. 넘길 때 스크롤을 맨 위 · 맨 왼쪽으로
- 기억: `scoremate.pageSpread`(기본 1쪽)
- 확인(헤드리스 Chromium, Moldau)
  - 데스크톱 2쪽 · 높이: 602×851 두 장이 나란히, 가운데 정렬
  - 2쪽 · 너비: 698 두 장
  - → 는 5–6, 끝까지 가면 13 / 13
  - 휴대폰 2쪽 · 너비: 193 두 장
