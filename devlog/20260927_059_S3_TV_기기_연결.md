## 1. 흐름 (TV 앱이 따를 것)

```
TV   POST /api/v1/device/code            {name?, model?, app_version?}   (인증 없음)
     → {device_code, user_code: "BCDF-GHJK", verification_uri: https://scoremate.noematica.kr/activate/,
        verification_uri_complete: …/activate/?code=BCDF-GHJK, expires_in: 600, interval: 5}
TV   화면: user_code 크게 + verification_uri_complete 를 QR 로
폰   /activate/?code=…  (로그인 → 돌아옴) → 코드 · 모델 확인 → 기기 이름 → [연결] / [거절]
TV   POST /api/v1/device/token  {device_code, grant_type?}   interval 초마다 (JSON 또는 form)
     400 {"error": "authorization_pending"}  계속 기다림
     400 {"error": "slow_down"}              간격 +5초
     400 {"error": "access_denied"}          거절됨 — 처음부터
     400 {"error": "expired_token"}          10분 지남 — 새 코드
     400 {"error": "invalid_grant"}          없는 코드 / 이미 토큰으로 바꿈
     200 {access_token, refresh_token, token_type: "Bearer", expires_in: 3600, device_id}   (Cache-Control: no-store)
이후 Authorization: Bearer <access_token>. 만료되면 POST /api/v1/auth/token/refresh/ {refresh} → {access, refresh}(회전)
     401 이면(기기 해제) 저장한 토큰을 지우고 연결 화면으로
GET  /api/v1/devices/me/   이 TV 의 정보(이름 · 마지막 접속)
```

## 2. 구현 (`backend/devices/`)

- `Device`(uuid, user, name, model, app_version, last_seen_at, revoked_at), `DeviceAuthorization`(device_code **해시**, user_code, status pending/approved/denied/used, interval, expires_at 10분, last_polled_at)
- user_code: 8글자, 헷갈리는 글자 · 모음 뺀 27자(초대 코드와 같은 규칙). 입력은 대소문자 · 하이픈 무시
- **device_code 는 SHA-256 해시로만 저장** — DB 사본(백업이 NAS 로 간다)이 새도 TV 행세를 못 한다
- 토큰은 **한 번만**(approved → used). 승인은 `select_for_update` 로 한 번만
- 기기 토큰: 모든 토큰에 `device_id` 클레임, refresh 수명 **180일**(`DEVICE_REFRESH_TOKEN_DAYS`)
- **해제는 즉시**: `DeviceAwareJWTAuthentication` 이 매 요청 `device_id` 의 기기가 살아 있는지 본다 — 이미 발급된 access(60분)도 막힌다.
  마지막 접속 시각은 5분에 한 번만 쓴다
- **refresh 회전**: simplejwt 기본 `TokenRefreshSerializer` 는 회전할 때 만료를 기본값(1일)으로 다시 정한다 → 기기 토큰이 첫 갱신 뒤 1일짜리가 된다.
  `DeviceAwareTokenRefreshSerializer`(설정 `TOKEN_REFRESH_SERIALIZER`)가 기기 토큰이면 180일을 유지하고, 해제된 기기의 refresh 를 거부한다
- 요청 제한: 코드 발급 IP 당 30/시간, 토큰 폴링 IP 당 2000/시간(5초 폴링은 익명 기본 100/시간을 넘는다), 웹 코드 조회 사용자당 30/시간

## 3. 웹
- `/activate/` — 코드 입력 → 확인(코드 · 모델 · 앱 · 기기 이름) → 연결/거절. 보기만 해서는 연결되지 않는다
- `/devices/` ("TV" 메뉴) — 이름 바꾸기 · 해제(기록은 남는다) · 마지막 접속
- API: `GET/PATCH/DELETE /api/v1/devices/`, `GET /api/v1/devices/me/`
