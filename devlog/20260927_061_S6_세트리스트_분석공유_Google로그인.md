## 0. 초대 전용 가입 (0.5.1)
- 운영 `.env` 에 `REGISTRATION_OPEN=false`. 스위치만 끄면 초대받은 새 사람도 가입할 수 없으므로 규칙을 바꿨다:
  **닫혀 있어도 쓸 수 있는 초대(`?invite=` 또는 next=`/join/<code>/`)가 있으면 가입할 수 있고, 가입과 함께 그 앙상블에 들어간다**
- 초대 없이 `/register/` → 안내(403). 로그인 화면은 초대 링크로 왔을 때만 "가입"과 초대받은 앙상블을 보인다
- API `/auth/register/` 는 `invite_code` 필요. 합류가 실패하면 계정도 만들지 않는다(원자적)

## 1. 앙상블 세트리스트 (연주회 곡목)
- `Setlist.ensemble`(null = 내 세트리스트, 앙상블을 지우면 함께 — 곡목은 앙상블의 것). 권한은 악보와 같은 `readable_by/writable_by`
- 넣을 수 있는 곡: 앙상블 곡목 = 그 앙상블 악보, 내 세트리스트 = 내가 올린 악보. 항목은 **읽을 수 있는 악보만** 보인다
- `GET /api/v1/sync/setlists/` — 볼 수 있는 세트리스트 전부(개수가 적어 커서 없이), 항목은 `score_id · position(1부터) · notes`.
  TV 는 받은 목록으로 통째로 바꿔 끼운다. 악보 자체는 `/sync/scores/`
- 웹: `/setlists/`(목록 · 만들기), 상세(곡 넣기 · ▲▼ · 빼기 · 메모 · 정보 · 지우기), 앙상블 화면의 "곡목", 메뉴 "세트리스트"

## 2. 악보 분석 공유
TV(MrgqPdfViewer v0.2.4)는 PDF 를 분석해 보표 시스템 · 마디 · 박자표를 만든다(`score_measures`). 서버에 두면
멤버 TV 가 다시 분석하지 않고, **모든 TV 가 같은 마디 번호를 쓴다**(합주 중 마디 동기화).

```
PUT /api/v1/scores/{id}/analysis/  {analyzer: "mrgq-measures", analyzer_version: "12", sha256, data: {...}}
    201 새로 · 200 바꿈 · 409 {"error": "mismatch" | "processing" | "not_newer"} · 413 too_large(1MB)
GET /api/v1/scores/{id}/analysis/[?version=n][&analyzer=]  → {version, analyses: [{analyzer, analyzer_version, sha256, data, …}]}
동기화 version.analyses = [{analyzer, analyzer_version, updated_at}] — 가진 것보다 새 것만 받는다
```
- 서버는 `data` 를 해석하지 않는다. **분석한 파일의 SHA-256 이 그 판의 것**이어야 받는다(다른 판 · 다른 파일의 분석이 섞이지 않게)
- 이미 있으면 멤버는 **더 새 분석기 버전**일 때만(버전은 숫자 마디 비교: 2.10 > 2.9), owner · leader 는 언제나(잘못된 분석 바로잡기)
- 저장하면 악보 `updated_at` 을 올려 멤버 TV 동기화가 알아챈다. 새 판은 분석 없이 시작한다

## 3. Google 로그인 (웹)
- OpenID Connect 인가 코드 흐름을 새 의존성 없이(`web/google.py`). state(CSRF) · nonce 는 세션에 두고 한 번만 쓴다
- ID 토큰은 서버가 토큰 엔드포인트와 TLS 로 직접 받으므로 서명 대신 TLS 서버 확인(OIDC Core §3.1.3.7). iss · aud · exp · nonce · **email_verified** 를 본다
- 계정 찾기: Google `sub` 로 연결된 사용자 → 같은(확인된) 이메일의 사용자에 연결 → 새 사용자(**초대 전용 규칙 그대로** — 초대 없으면 403)
- `SocialAccount(provider, subject, email)` — 다음부터는 sub 로(구글 쪽 이메일이 바뀌어도 같은 사람)
- Google 로 가입한 계정은 비밀번호가 없다 — 계정 화면에서 기존 비밀번호 없이 정할 수 있다
- TV 는 여전히 기기 코드(059)로 — Google 로그인은 휴대폰 · PC 웹용

## 4. Google 로그인 켜기 (사람이 할 일)
1. Google Cloud 콘솔 → API 및 서비스 → 사용자 인증 정보 → OAuth 클라이언트 ID 만들기 → 웹 애플리케이션
2. 승인된 리디렉션 URI: `https://scoremate.noematica.kr/auth/google/callback/`
3. (처음이면) OAuth 동의 화면: 외부, 범위 `openid · email · profile`
4. dolfinid `/srv/scoremate/.env` 에 `GOOGLE_CLIENT_ID=…` · `GOOGLE_CLIENT_SECRET=…` 추가 →
   `cd /srv/scoremate && docker compose up -d --force-recreate`(env_file 은 재생성해야 읽힌다) 또는 다음 배포
