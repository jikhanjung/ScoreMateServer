## 0.7.1 — 고르기 화면 정리

### 문제
TV 화면의 "받는 것" 고르기에서 체크박스 · 라디오가 흩어지고 카드가 정돈되지 않았다.
원인은 텍스트 칸용 스타일을 그대로 받은 것:
- `.row > input { flex: 1 1 140px }` — 체크박스가 140px 로 늘어나 글자와 떨어짐
- `.field label` — 블록 라벨 스타일이 선택지마다 붙어 줄이 어긋남

### 고친 것
- **CSS**(`web/static/web/app.css`) — 선택지 전용 클래스를 따로 둠
  - `.choice`: 입력 + 글자를 한 줄로 묶음(입력은 늘어나지 않음). `.field .choice` 로 라벨 스타일을 덮음
  - `.option`: 선택지 하나를 테두리 상자로. `:has(input:checked)` 로 고른 것을 강조
  - `.checklist`: 세트리스트 체크 목록을 격자로
  - `.option.all-selected`: "모든 악보"를 고르면 세트리스트 목록을 흐리게(작은 JS 로 토글)
  - `.device`: 기기 카드
- **TV 화면**(`web/devices/list.html`) — 기기마다 카드 하나
  - 머리: 이름 · 모델 · 앱 버전 · 마지막 접속/동기화 · 연결일, 해제 버튼
  - 이름 바꾸기는 `<details>` 로 접어 둠
  - 받는 것: "고른 세트리스트만"(체크 목록) / "모든 악보"
  - 해제한 기기는 아래 별도 목록에 작게 — 뷰 `device_list` 가 `devices`(활성) · `revoked` 로 나눠 넘김
- **세트리스트 화면**(`web/setlists/detail.html`) — "보낼 TV"와 "곡 넣기"를 체크 목록으로.
  "곡 넣기"는 Ctrl 을 눌러야 하던 여러 줄 선택 상자 대신 체크
- **TV 연결 화면**(`web/devices/activate.html`) — 같은 선택지 스타일

### 확인
데모 서버에서 화면을 직접 확인했다. `--noreload` 로 띄운 서버는 템플릿을 캐시하므로 다시 띄워야 바뀐 화면이 보인다.
전체 테스트 350개 통과.

## 0.7.2 — 상단 ScoreMate 옆에 버전
- `web/base.html`: `ScoreMate <span class="brand-version">v{{ app_version }}</span>`
- `app_version` 은 컨텍스트 프로세서(`web/context_processors.py`)가 `scoremateserver/version.py` 에서 읽는다.
  `build.sh` 가 배포마다 올리므로 **따로 고칠 것이 없다**. 요청은 "v0.7.1"이었지만 이 변경 자체가 0.7.2 라 v0.7.2 로 보인다
- `.brand-version`: 작게 · 보통 굵기 · 흐린 색
- 테스트: `tests/test_web.py::BrandVersionTest` — 로그인 화면에 `v{VERSION}` 이 보이는지. 전체 351개 통과
